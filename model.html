STEP 8｜PPML 固定效果模型

不是問「誰課多」，而是問「同一所學校六年來怎麼變」

正式模型用 institution-lineage fixed effects，把每校不隨時間改變的特質吸收掉，再比較 AY109 到 AY114 的 within-institution 變化。

模型在算什麼？

E(Y_it|X_it) = exp(α_i + λ_t + Σδ_t[Tech_i × Year_t])

白話：先把每一所學校自己的「基本體質」固定住，再看年度變化；最後用 Tech × Year 交互作用 檢查科技大學的變化軌跡是否和一般大學不同。

為什麼用 PPML？

課程數是 0、1、2、3… 的非負計數，而且變異很大。資料有明顯 overdispersion；NB2 在 pooled distribution fit 上較佳，但研究關心的是條件平均的縱向變化，因此正式估計採 PPML fixed effects + cluster-robust SE。

重要固定效果模型會吸收「大學類型」這種不隨時間改變的主效果，所以正式模型不是直接估計「科技大學天生比一般大學多幾門」。它估的是「變化是否不同」。

三個名詞先記住

PPML
Poisson Pseudo-Maximum Likelihood｜卜瓦松擬最大概似估計

IRR
Incidence-Rate Ratio｜計數率比

Fixed Effects
固定效果：控制每校不隨時間改變的特質

主要 PPML 結果

1.714
一般大學 Broad：AY114 vs AY109 IRR
95% CI 1.497–1.963，p < .001

白話：約為 AY109 的 1.714 倍，亦即模型估計的條件平均增加約 71.4%。

1.741
一般大學 Core：AY114 vs AY109 IRR
95% CI 1.497–2.024，p < .001

核心課程也有明顯的 within-institution 增長。

科技大學 Broad

合併年度主效果與 Tech × AY114 後，估計 IRR 約 1.727。

Tech × AY114 interaction = 1.008，p = .956。

科技大學 Core

合併後 AY114 vs AY109 IRR 約 2.026。

Tech × AY114 interaction = 1.164，p = .326。

真正的主結論看「聯合檢定」Broad 的五個 Tech × Year 交互作用聯合 Wald p = .820；Core 的聯合 Wald p = .901。因此目前沒有足夠證據支持兩類大學的六年成長軌跡系統性不同。
不要說「兩類大學完全一樣」不顯著只能表示資料與模型沒有偵測到系統性差異；估計值仍可能不同，且樣本、測量誤差與統計力都會影響結果。

樣本怎麼變少了？

Broad model

N = 572 institution-years；97 lineages；43 個 all-zero lineages 被固定效果模型排除。

Core model

N = 536 institution-years；91 lineages；49 個 all-zero lineages 被排除。

理由：如果某校在整段期間該 outcome 永遠是 0，該校固定效果無法在 Poisson FE 中被識別。這不是任意刪資料，而是估計器的識別條件。
