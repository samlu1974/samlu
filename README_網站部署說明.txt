台灣大專校院半導體課程計量分析｜說明網站

開啟方式
1. 解壓縮整個資料夾，請勿只取出 index.html。
2. 直接雙擊 index.html，即可離線瀏覽。
3. 若要公開部署，可把整個資料夾上傳 GitHub Pages、Netlify、Cloudflare Pages 或任何靜態網站空間。

內容
- 11個網頁：首頁、圖卡說帖、背景、STEP0–12、分類、模型、結果、產業對應、影響報告、術語、來源限制。
- 21張資訊圖卡已轉為本機 WebP，網站不依賴外部圖片主機。
- 無外部JavaScript框架或字型依賴。

研究解讀原則
- STEP8–10為縱貫／描述／關聯證據，不是政策因果效果。
- 修課人次為課程登記人次，不是unique students。
- STEP10 gap為文件型戰略基準下的相對低配，不等於勞動市場缺工。
- AI輔助分類尚未完成真正獨立盲人類外部驗證。
